# Code Rain 🟩

Animated digital code rain for your phone — with a lock-screen style clock, live BTC/ETH charts, weather and your own notes.
手机上的动态代码雨：可叠加锁屏风格的大时钟、BTC/ETH 实时走势、天气和你自己的备忘。

**▶ Try it / 立即打开：https://jkhoo8811.github.io/coderain/**

## Versions / 版本

Each link remembers its own settings. Add several to your Home Screen as separate apps.
每个链接各自记住设置，可以分别添加到主屏幕，当成几个独立的 App。

|---|---|---|

| Cyan, big clock / 青色大时钟 | [open](https://jkhoo8811.github.io/coderain/?hud=clock&theme=cyan&lang=en) | [打开](https://jkhoo8811.github.io/coderain/?hud=clock&theme=cyan&lang=zh) |
| Red, rain only / 红色纯代码雨 | [open](https://jkhoo8811.github.io/coderain/?theme=red&lang=en) | [打开](https://jkhoo8811.github.io/coderain/?theme=red&lang=zh) |

URL options / 网址参数：`theme` = green · cyan · red · gold · purple · rainbow；`hud` = off · clock · full；`lang` = en · zh；`speed` = 0.5 – 2；`title` = intro text / 开场标题。

## Controls / 操作

| Gesture | Action | 手势 | 作用 |
|---|---|---|---|
| Tap | Change colour + ripple | 点一下 | 换颜色，荡开一圈光波 |
| Drag left/right | Wind | 左右拖动 | 风吹斜 |
| Double-tap | Pause | 双击 | 暂停 |
| Long-press | Menu: info mode, notes, photo, speed, title, language | 长按 | 菜单：信息模式、备忘、照片、速度、标题、语言 |

**Photo mode / 照片模式：** pick a photo and it is redrawn out of code — bright areas glow, dark areas fade.
选一张照片，它会变成由代码组成的样子：亮处代码亮，暗处几乎看不见。

**Notes / 备忘：** separate items with `;` — e.g. `Mum's birthday 16/10; Dentist 18/10`.
多条用分号隔开。

## Install on iPhone / 装到 iPhone

**Option A — Home Screen app / 主屏幕 App（全屏）**
1. Open a link above in **Safari** / 用 **Safari** 打开上面的链接
2. Share → **Add to Home Screen** / 分享 → **添加到主屏幕**

**Option B — Shortcuts / 快捷指令（可配合背面轻点、操作按钮）**
1. Shortcuts → **+** → add **URL** → paste a link above / 快捷指令 → **＋** → 添加「URL」→ 粘贴链接
2. Add **Show Web Page** / 添加「显示网页」
3. Optional: Settings → Accessibility → Touch → **Back Tap** → choose the shortcut / 可选：设置 → 辅助功能 → 触控 → **轻点背面** → 选这个快捷指令

> iOS lock screens only accept still images, so this runs as an app, not as a live lock-screen wallpaper.
> iOS 锁屏只能放静态图片，所以它是一个打开来看的 App，不是动态锁屏壁纸。

## Privacy / 隐私

Everything stays on your device. Your photo, notes and settings are saved in your own browser only and are never uploaded. The page only reads public data: BTC/ETH prices from Binance's public market API and weather from Open-Meteo. No accounts, no tracking, no ads.
所有内容只留在你的手机里。照片、备忘和设置只存在你自己的浏览器，不会上传。网页只读取公开数据：币安公开行情接口的币价、Open-Meteo 的天气。不用注册，不追踪，没有广告。
